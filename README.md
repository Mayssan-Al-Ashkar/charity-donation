# 🌍 Charity - Donate for a Cause

A modern **Charity Donation Web Application** built with **Laravel** (as the backend) and **React** for the frontend UI.  
The platform allows users to explore charity causes, donate securely using **Razorpay**, and track their contributions.

---

## 🧩 Tech Stack

**Backend:** Laravel 12 (PHP 8.3+)  
**Frontend:** React Js & Bootstrap
**Database:** MySQL  
**Payment Gateway:** Razorpay 
**Storage:** Local Storage

---

## ⚙️ Installation


### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Mayssan-Al-Ashkar/charity-donation.git
cd charity-donation
```
2️⃣ Install Dependencies
```bash
composer install
```

3️⃣ Configure Environment


4️⃣ Run Migrations and Seeders
```bash
php artisan migrate
php artisan db:seed
```
